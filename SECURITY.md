# Security

This repository contains documentation and media only. It contains no source code, credentials, databases or deployment configuration.

If you believe something published here exposes personal data, a credential, or a security issue in HollyEarth, please report it privately rather than opening a public issue, and do not include personal data in a public issue. Contact information will be published through the official HollyEarth / Lab Da Riga channels.

Personal data appearing in screenshots or videos is reviewed before publication (see [media/SCREENSHOT_PLAN.md](media/SCREENSHOT_PLAN.md)). Requests to remove or blur a person, address or other detail are handled promptly.
