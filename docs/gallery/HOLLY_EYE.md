> **Holly Eye is a third-party integration, not HollyEarth Core.**
> It is the open-source application **God's Eye View by Bilawal Sidhu** (stated licence: MIT), run as a separate application and connected to HollyEarth by the **World** door, with a way back to the Riga Twin.

## The door

<a href="../../media/screenshots/01-start.png"><img src="../../media/screenshots/01-start.png" alt="Start screen with the World area" width="100%"></a>

The **World** area on the start screen is labelled `BETA` and "world layers". It opens Holly Eye, or says plainly that the application is not running and how to start it (`WORKING`).

## Inside Holly Eye — `BETA`

A photorealistic globe with first-view choices (live contacts, space missions, environmental events, explore manually) and side panels for data layers, scenes, display and location. English only; it opens outside Riga and holds no HollyEarth graph or case data.
