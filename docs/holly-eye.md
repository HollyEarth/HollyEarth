# World — Holly Eye

The **World** door in HollyEarth opens **Holly Eye**, a planetary 3D view.

> **Holly Eye is a third-party integration, not HollyEarth's own technology.**
> It is the open-source application **God's Eye View** by **Bilawal Sidhu** (stated licence: MIT), run as a separate application at a pinned version with HollyEarth integration patches, and connected to HollyEarth by a door and a way back to the Riga Twin.

## Status

| Part | Status | Notes |
|---|---|---|
| World door in HollyEarth | `WORKING` | Opens Holly Eye, or says plainly that it is not running and how to start it |
| Holly Eye planetary view | `BETA` | Photorealistic globe with world layers (for example live contacts, space missions, environmental events) from third-party sources |
| Voice commands in Holly Eye | `PROTOTYPE` | Push-to-talk map commands; internal setting only; uses paid speech services |
| HollyEarth data inside Holly Eye | `FUTURE` | Holly Eye holds no Riga, graph or case data |

## Limits

- English only; opens outside Riga.
- Depends on third-party map tiles, data layers and keys; some features stay unavailable without them.
- Third-party data and imagery terms apply and are being reviewed — see [DATA_SOURCES.md](../DATA_SOURCES.md) and [NOTICE.md](../NOTICE.md).

No Holly Eye screenshot is published yet, pending a review of third-party imagery terms.
