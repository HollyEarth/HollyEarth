# Story

A case can **tell itself**. Story turns an investigation into a sequence of chapters — what was observed, the pattern, the question, possible explanations, the evidence needed, the next step, the current conclusion — while the case's network is directed on screen chapter by chapter.

- **Lengths** — short (≈1 min), brief (≈3 min), detailed (≈9 min).
- **Languages** — Russian, Latvian, English; a saved telling is rendered in each language from the same underlying plan.
- **Only confirmed** — an option to tell only what is supported, leaving partial links as traces rather than facts.
- **Versions** — tellings are saved as versions; when the case has changed since a telling was made, the telling says so.

## Assembled, not invented
The structure of every telling comes from the case's own records. A language model may optionally help with wording inside that structure, but it cannot add facts or chapters, and a complete telling exists without any model.

## Voice
Narration is optional: a browser voice, a local voice model, or a hosted voice service that is used only after explicit confirmation. Voice is **BETA**.
