# HollyEarth — public concept infographics

Twelve original, editable **SVG** storyboards prepared for HollyEarth's public presentation. These are **concept visuals**, not product screenshots, UI proofs, product design source files, production architecture, or independently verified research. Use the real screenshots and feature-status matrix for claims about current capabilities.

**Style:** ivory porcelain, champagne gold, sage-green technical engraving, quiet geometric motifs. No external images, brand marks, map tiles or fonts were embedded.

**Series:** Overview · City · Politics · Sport · Social · Investigation · Intelligence · Experience · HollyWorlds · Research · Future · Capabilities.

Every language's README uses the same visuals with translated supporting text. Labels in the SVG files use short English headings so the assets can remain shared. All real product screenshots, data-origin notices, third-party credits, tables and existing galleries are retained.

**Product maturity:** separate Unreal Engine prototypes are described in README, but are not represented as a connected HollyEarth v0.1.0 feature or as a completed Bolderāja mission system.
