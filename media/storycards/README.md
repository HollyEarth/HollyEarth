# HollyEarth · Living Stories

Eleven original vector illustrations, one for each HollyEarth section. These are conceptual journeys from a human question to a tangible value, **not product screenshots**. They are designed in the HollyEarth ivory, champagne-gold and deep-teal visual language.

The SVGs use editable vector shapes and text; currently the artwork text is English. The documentation surrounding them is available in EN / RU / LV.

For working functions and their caveats, see [Feature Status](../../docs/FEATURE_STATUS.md). Existing screenshots in the README and Visual Atlas remain the actual product evidence.
